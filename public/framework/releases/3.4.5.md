# Framework v3.4.5

Released on 2026-11-06.

## Framework Changes

- A long title bar title or instance name ends in an ellipsis inside the bar, instead of running to the edge of the view and being cut mid-letter. The instance gives way first, so a short title stays whole. Title bars that already fit render the same pixels.

## Upgrade Notes

- Plugins pinned to 3.2.0 through 3.4.4 keep the cut-off title bar until they move to 3.4.5.
