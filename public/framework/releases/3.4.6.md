# Framework v3.4.6

Released on 2026-11-06.

## Framework Changes

- When a title fills the whole title bar, the instance is hidden instead of showing a sliver of its first letter.
- A one-line `data-clamp` in a `.grid` or `.flex` cell fits the text's own box, not the whole cell, so the ellipsis is no longer cut off by the cell's padding or `.meta` bar.
- `data-value-fit-max-height` is capped to the height the layout has, so a quadrant markup in a smaller mashup cell no longer runs past the cell.
