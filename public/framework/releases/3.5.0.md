# Framework v3.5.0

Released on 2026-10-15.

## Framework Changes

- Text in `label--primary`, `label--success`, `label--error` and `label--warning` is black or white, whichever has more contrast on the color the screen actually paints. On TRMNL color screens this fixes white text on yellow labels (Black, White and Yellow panels in light mode, and every color panel in dark mode).
- Text inside a `bg--*` background follows the same rule on 2-bit, 4-bit and color screens, so dark gray cards no longer carry black text. A `text--*` class or your own CSS still wins, and 1-bit screens are unchanged.
- Canvas, surface and backdrop backgrounds, the title bar, item and table `.meta`, the map attribution and `text-stroke` text keep the screen's own text color inside a `bg--*`.

## Upgrade Notes

- Plugins pinned to an earlier version keep their current text colors until they move to 3.5.0. To keep a specific color inside a `bg--*`, add a `text--*` class.

## Documentation Changes

- The Label and Background pages describe how the text color is chosen.
