# TRMNL bundle

Three font families, each with Regular and Bold weights.

This zip contains every font file required by the **TRMNL** bundle of the
[TRMNL Framework](https://usetrmnl.com), together with the **Inter Variable** typeface
used on high-density displays. Activate the bundle in your markup by adding
`screen--fonts-trmnl` to the screen root.

Released on 2026-07-31.

## Pixel fonts


### TRMNL12

The smallest pixel font, used for descriptions, small labels, and metadata.

- **Designed at:** 12px pixel height
- **Weights:** normal, bold
- **Formats:** woff2, woff, ttf
